# Reference-led refinement

The latest pasted feedback takes precedence over the earlier broad redesign brief:
preserve the navy/teal palette, generated N-loop logo and anatomical brain geometry.
Refine composition and interaction rather than replacing the identity.

## Reference review

The supplied sites were opened in a disposable Edge browser using software WebGL.
Screenshots and visible-text records are in `data/verification/refinement/references`.

- [Trionn](https://trionn.com/): large typographic transitions and spatial composition.
- [HLE](https://hle.io/): strong text hierarchy and ample negative space.
- [Edolus](https://edolus.com/): reviewed its opening and exposed page text; its heavy loading scene did not finish within the bounded browser inspection.
- [Share Bien](https://www.sharebien.com/): compact floating navigation and layered presentation.
- [Run Rob Run](https://www.runrobrun.com/): expressive central form, broad typography and motion-led composition.
- [Noomo storytelling](https://storytelling.noomoagency.com/): reviewed exposed narrative structure; the WebGL opening stayed on its loader in this test environment, so its full visual sequence was not verified.
- [Manish](https://www.manishkr.xyz/): inspected the entry and content after choosing entry without sound; restrained navigation and an animated character-based visual.

NeuroLoop keeps its own colors and anatomy. New details include a diagonal split
login with an anatomical point cloud, progressive disclosure for token access,
section and hover motion, clearer navigation, profile icons, and a favicon viewport
that enlarges the existing mark without altering the original PNG. Decorative status
dots and the sidebar's inset active line are removed.

## Functional changes

- Compare disables incompatible model profiles before submission and explains what
  the numerical comparison measures.
- Brain geometry readiness is explicit. The old five-second wait has been removed;
  failed requests expose retry controls. Hemisphere spacing is a separate checkbox
  alongside the three mutually exclusive display modes.
- Research includes actual cortical timelines, compute plots, intervention tables
  and an evaluation register. Archived evidence can be included explicitly.
- The marimo companion uses the same palette, named creatives, ledger tabs,
  compute charts and a return link to the workspace.
- MCP exposes 15 real tools, live parameter schemas, a working Codex CLI command,
  and separate connection checks for sponsor services.
- Each neural evaluation executes in its own child process. The previous run-level
  model retention caused a real second-candidate RAM refusal. Process exit now
  releases encoder allocations before the next candidate. Memory guards remain.
