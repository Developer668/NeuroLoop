# Evidence and scientific boundaries

File decoding, dimensions, aspect ratio/duration and storage checks are deterministic. Logo/product identity, language claims, visual fidelity, hook/CTA and similar semantic checks require a genuine configured evaluator. An image alone does not prove product facts. Unknown required checks block eligibility.

The current ranking field is a vision creative_quality proxy, not an empirical sales prediction. TSAM and TRIBE evidence remains separately typed and versioned; their raw scales are not arbitrarily averaged. Required evaluators must use compatible checkpoint/configuration hashes across compared candidates. Disagreement can stop the run rather than disappearing into a mean.

TSAM predicts an affective proxy, not a named person's feelings. TRIBE predicts average cortical responses, not the user's brain or intent. Every neural result requires interpretation limitations. Brain Lab displays real fsaverage5 artifacts only; an uncolored anatomical surface is explicitly labeled anatomy-only.

Stochastic generated variants have variant_level attribution. Real Meta reports retain reporting interval, retrieval timestamp and missing fields; empty results are empty, not zero-valued invented conversions. Automatic causal attribution and statistical winner declaration are not implemented.
