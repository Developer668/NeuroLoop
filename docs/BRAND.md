# NeuroLoop identity

## Assistant assets

The assistant is named Neuro AI. Its page, navigation mark and response avatar use the user-supplied flat image at `frontend/public/brand/neuro-ai.png`. The textured `neuro-assistant-v1.png` remains an unused historical asset. The assistant still executes local evidence commands; this visual update does not enable a conversational model.

The logo was generated using the built-in GPT Image tool, then copied unchanged to `frontend/public/brand/neuroloop.png`. The original remains in the Codex generated-images directory. The interface uses navy, teal, white and mineral gray. The wordmark is live text next to the generated symbol; no mock customer logos, invented metrics or endorsements are used.

Generation prompt:

> Create one exceptional premium technology brand logo symbol for NeuroLoop, a scientific creative experimentation platform. A precise, original continuous folded loop suggesting both the letter N and two communicating cortical hemispheres, abstract geometric mark, architectural elegance, distinctive at 24px. Flat vector-like silhouette, deep navy #102B3F with a restrained teal #137D83 second face, beautifully balanced negative space, no gradients, no shadows, no 3D rendering, no literal brain squiggles, no circuit cliché, no text or letters outside the symbol, no mockups. Center a single compact logo mark on a pure white background, generous surrounding white space, crisp clean edges, professional identity design.

The landing-page sculpture uses actual fsaverage5 anatomy, rendered as points. Rotation is capped at 20 rendered frames per second and pauses when offscreen or when the tab is hidden. Operating-system reduced motion disables it. Workspace rendering occurs on demand when the camera, mode or selected response changes.
